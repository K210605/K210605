## 🚀 Featured Projects

### 🚨 Transaction Fraud-Spike Detector

An industrial-style fraud risk platform built for the Razorpay AI Buildathon (Track 2 – AI Risk Manager). Combines statistical rolling-window/z-score detection with an Isolation Forest ML model, backed by a FastAPI service and a live-updating dashboard with real-time transaction simulation and evaluation metrics.

**Tech:** Python • FastAPI • SQLite • scikit-learn • Chart.js • HTML/JS

### 🔐 Password Cracker Toolkit (v2)

A Java-based cybersecurity research project benchmarking multiple password-cracking algorithms (Brute Force, Dictionary, Hybrid, Mask, Markov Chain) behind a common interface, with a dark/neon JavaFX GUI featuring login flow and an internal hash-generation module.

**Tech:** Java • JavaFX • Maven • Cryptography (SHA-256)

### 🌳 MST Visualizer

Interactive visualization of **Kruskal's and Prim's algorithms** for understanding Minimum Spanning Trees.

**Tech:** Java • JavaFX • Algorithms

### 🧮 Matrix Chain Multiplication Visualizer

A GUI-based implementation for visualizing Matrix Chain Multiplication and finding the optimal parenthesization.

**Tech:** Java • JavaFX • Dynamic Programming

### 🛡️ Cybersecurity Labs

**Tech:** Linux • Networking • Cybersecurity Tools
